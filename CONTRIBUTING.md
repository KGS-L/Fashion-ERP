# Contributing to Ivadoo

Thank you for your interest in contributing to Ivadoo.

Ivadoo is being developed as a modular open-core ERP for fashion, textile and garment businesses.

The project was originally developed under the working name **FashionERP**. Some stable internal namespaces and historical material still use that legacy name while the public product brand is Ivadoo.

## Before contributing

For significant changes, please open an issue first to describe the problem, proposal or feature you want to work on.

Keep contributions focused and avoid mixing unrelated changes in the same pull request.

## Development principles

Contributions should respect the main project principles:

- modular architecture;
- clear business-domain boundaries;
- multi-company and multi-establishment support;
- strict access control and tenant isolation;
- internationalization from the beginning;
- traceability and auditability for sensitive operations;
- automated tests for critical behavior.

## Pull requests

Before opening a pull request:

- make sure the project builds correctly;
- run the relevant tests;
- update documentation when behavior changes;
- use clear commit messages;
- keep the pull request as small and focused as reasonably possible.

## Licensing

Contributions to Community components are accepted under the license applicable to those components, currently LGPL-3.0-only unless otherwise stated.

Commercial or proprietary Ivadoo components may be governed by separate contribution and licensing rules.

## Code of conduct

Contributors are expected to communicate professionally and respectfully when discussing issues, reviews and technical decisions.
