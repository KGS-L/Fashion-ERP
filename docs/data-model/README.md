# Data model

Documentation for FashionERP entities, relationships and cross-cutting data rules.

The specification defines core entities such as Organization, Company, Establishment, Workshop, Store, Warehouse, User, Customer, Supplier, Employee, Product, Variant, Material, Collection, Design, Measurement, Order, ManufacturingOrder, StockMovement, PurchaseOrder, QualityInspection, Delivery, Expense, Invoice, Payment, JournalEntry, Document, Notification, License and Subscription.

Detailed schemas will be added progressively as module specifications are validated.
