# Architecture

Architecture documentation for FashionERP.

This section describes the platform structure, including:

- Control Plane and Data Plane separation
- Organization, company and establishment hierarchy
- Modular ERP boundaries
- PostgreSQL data architecture
- S3/MinIO document storage
- REST and OpenAPI principles
- Desktop, workshop mobile and client-facing applications
- Managed cloud, customizable cloud, on-premise and private server deployments

Architecture documents must remain aligned with the validated specification.
