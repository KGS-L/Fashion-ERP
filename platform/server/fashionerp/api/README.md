# Server API infrastructure

This package contains the cross-cutting REST infrastructure shared by FashionERP API resources.

## Foundation contract

The Phase 1 API baseline is:

- Django REST Framework;
- versioned business API under `/api/v1/`;
- OpenAPI generated by drf-spectacular;
- schema at `/api/schema/`;
- interactive documentation at `/api/docs/`;
- opaque Bearer authentication for protected resources;
- deny-by-default server-side authorization;
- standard page-number pagination;
- explicit allow-lists for filtering, search and ordering;
- stable JSON error envelope;
- explicit POST actions for state-changing domain operations.

## Current Foundation namespaces

Only Foundation capabilities are routed in Phase 1:

- `/api/v1/auth/` — authentication, sessions/devices and 2FA;
- `/api/v1/organizations/` — local organization read boundary;
- `/api/v1/companies/` — company hierarchy;
- `/api/v1/establishments/` — establishment hierarchy;
- `/api/v1/access/` — users, roles, groups, permissions and grants;
- `/api/v1/audit/` — immutable audit reads;
- `/api/v1/i18n/` — Foundation international settings.

The organization collection is intentionally unpaginated because a Data Plane database contains exactly one local Organization. Other unbounded collections use the standard pagination contract.

## Explicit exclusions

Phase 1 does not expose business-module routes for customers, products, measurements, orders, inventory, purchases, manufacturing, deliveries or reports.

API keys and webhooks are not part of the Foundation internal API. The specification reserves them for Enterprise Plus.

## Contract verification

The API contract test suite verifies that:

- every implemented Foundation route is represented in OpenAPI;
- the opaque Bearer security scheme is present;
- collection pagination/filter/search/ordering parameters are represented;
- the standard error envelope is stable;
- Phase 2 routes are absent;
- Enterprise Plus API-key/webhook routes are absent.

CI also generates and validates the OpenAPI schema using:

`python manage.py spectacular --file /tmp/fashionerp-openapi.yaml --validate`
