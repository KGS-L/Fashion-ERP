# Customers

Phase 2 customer master data for FashionERP.

This module implements customer records, contacts, addresses, preferences and consent records needed by the custom-order workflow.

It deliberately does not implement Phase 4 CRM concepts such as leads, opportunities, pipelines, commercial follow-up or advanced segmentation.

Customer data is always attached to the local Organization and a Company. An optional Establishment identifies the owning/primary site while preserving Company-level ownership.
