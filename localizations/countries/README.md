# Country localizations

Country-specific Ivadoo localization modules belong here.

A country localization may define the fiscal, accounting, tax, legal document and regulatory adaptations required for that country.

Common ERP business rules must remain outside country localization modules so that adding a new country does not require rewriting sales, purchasing, inventory or manufacturing logic.

No country-specific implementation is created yet because the first accounting and fiscal localization is still an open project decision.
